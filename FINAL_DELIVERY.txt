【开关逻辑】
  总开关 = OFF  → 所有渠道禁用
  总开关 = ON   → 检查各渠道开关
    ├─ WxPusher = ON  → 发送
    ├─ WxPusher = OFF → 跳过
    ├─ PushPlus = ON  → 发送
    ├─ PushPlus = OFF → 跳过
    ├─ Resend = ON    → 发送
    ├─ Resend = OFF   → 跳过
    ├─ Telegram = ON  → 发送
    └─ Telegram = OFF → 跳过

【状态指示】
  🟢 已启用并生效  - 总开关开启 + 渠道开关开启 + 凭证已配置
  🟡 已禁用        - 总开关开启 + 渠道开关关闭
  🔴 不可用        - 总开关关闭（忽略渠道开关状态）

【配置持久化】
  存储文件: notification_config.json
  格式: JSON
  自动创建: 首次保存时
  实时生效: 无需重启应用

【方式一：一键安装（推荐）】

  1. 运行安装脚本
     $ ./setup.sh
  
  2. 编辑配置
     $ nano .env
     修改: DB_PASSWORD 和 HF_HOME
  
  3. 启动应用
     $ python app.py
  
  4. 访问界面
     http://localhost:7860

【方式二：手动安装】

  1. 创建虚拟环境
     $ python3 -m venv venv
     $ source venv/bin/activate
  
  2. 安装依赖
     $ pip install -r requirements.txt
  
  3. 配置数据库
     $ psql -U postgres -c "CREATE DATABASE text2image_db;"
     $ python database/init_db.py
  
  4. 配置环境
     $ cp .env.example .env
     $ nano .env
  
  5. 启动
     $ python app.py

【场景1: 首次使用】

  Step 1: 配置通知凭证
    $ nano .env
    添加至少一个渠道的凭证
  
  Step 2: 启动应用
    $ python app.py
  
  Step 3: 设置通知开关
    访问 http://localhost:7860
    → 切换到 "🔔 通知设置" 标签
    → 调整总开关和渠道开关
    → 点击 "💾 保存设置"
  
  Step 4: 生成图片
    → 切换到 "🖼️ 生成图片" 标签
    → 输入文本描述
    → 点击 "🎨 生成图片"
    → 等待完成
    → 自动收到通知（已启用的渠道）

【场景2: 只使用邮件通知】

  通知设置:
    ☑ 启用通知 (总开关)
    ☐ WxPusher
    ☐ PushPlus
    ☑ Resend Email    ← 只开启邮件
    ☐ Telegram
    
  → 保存设置
  → 生成图片时只发送邮件通知

【场景3: 临时关闭通知】

  需求: 批量生成图片，不想收到大量通知
  
  操作:
    → 切换到 "🔔 通知设置"
    → 关闭总开关
    → 保存设置
    → 生成图片（不会发送通知）
    → 完成后重新开启总开关
