【后端技术栈】
  • Node.js (v14+)           - JavaScript 运行环境
  • Express.js               - Web 应用框架
  • PostgreSQL               - 关系型数据库
  • WebSocket (ws)           - 实时双向通信
  • yt-dlp                   - YouTube 下载工具
  • Puppeteer                - PDF/PNG 生成
  • Axios                    - HTTP 请求库

【前端技术栈】
  • 纯 HTML5                 - 语义化标签
  • 纯 CSS3                  - Grid + Flexbox + 渐变
  • 纯 JavaScript (ES6+)     - 无框架依赖
  • WebSocket API            - 实时通信
  • Fetch API                - 异步请求

【数据库设计】
  • videos 表（15个字段）
    - 基本信息：id, url, title, filename
    - 格式信息：video_format, audio_format
    - 文件信息：video_size, audio_size, duration
    - 路径信息：video_path, audio_path
    - 状态信息：status, error_message
    - 时间信息：created_at, completed_at
    - 额外信息：thumbnail_url, description

【方式一：一键安装（推荐）】

  $ ./setup.sh              # 自动检查依赖并安装
  $ npm start               # 启动服务器
  
  访问: http://localhost:3000

【方式二：手动安装】

  $ npm install             # 安装 Node.js 依赖
  $ cp .env.example .env    # 复制配置文件
  $ nano .env               # 编辑配置（数据库密码等）
  $ npm run init-db         # 初始化数据库
  $ npm start               # 启动服务器

【验证安装】

  $ ./verify.sh             # 运行验证脚本
  
  该脚本会检查：
  • 系统依赖是否安装
  • 项目文件是否完整
  • 数据库连接是否正常
  • 网络连接是否可用

【必须配置】
  .env 文件中的数据库配置：
  
  DB_HOST=localhost              # 数据库主机
  DB_PORT=5432                   # 数据库端口
  DB_NAME=youtube_downloader     # 数据库名称
  DB_USER=postgres               # 数据库用户
  DB_PASSWORD=your_password      # 数据库密码（必须修改）

【可选配置】
  • PORT=3000                    # 服务器端口
  • DOWNLOAD_DIR=./downloads     # 下载目录
  • MAX_CONCURRENT_DOWNLOADS=3   # 最大并发下载数

【通知配置（可选）】
  • WXPUSHER_TOKEN               # WxPusher 推送
  • PUSHPLUS_TOKEN               # PushPlus 推送
  • RESEND_API_KEY               # Email 通知
  • TELEGRAM_BOT_TOKEN           # Telegram 通知

【首次使用建议】
  1. 先运行 ./verify.sh 检查环境
  2. 阅读 WELCOME.md 了解基本使用
  3. 下载 1-2 个视频测试功能
  4. 配置通知（可选）
  5. 开始批量下载

【性能优化建议】
  • 根据网络和机器性能调整并发数
  • 合理选择视频质量（不是越高越好）
  • 定期清理下载文件释放空间
  • 使用搜索和筛选功能管理视频

【安全建议】
  • 修改默认数据库密码
  • 不要在公网暴露服务
  • 定期备份数据库
  • 遵守 YouTube 服务条款
