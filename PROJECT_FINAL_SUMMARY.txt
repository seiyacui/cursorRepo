【场景1: 生成图片并查看日志】
  1. 启动应用: python app.py
  2. 另开终端: tail -f logs/generator.log
  3. 生成图片
  4. 观察日志输出:
     • 生成开始（提示词、参数）
     • 生成成功（路径、尺寸、大小、耗时）
     • 数据库保存（记录ID）
     • 通知发送（渠道列表）

【场景2: 只启用邮件通知】
  1. 访问 "🔔 通知设置" 标签
  2. 保持总开关开启
  3. 关闭 WxPusher、PushPlus、Telegram
  4. 开启 Resend Email
  5. 保存设置
  6. 生成图片
  7. 只收到邮件通知
  8. 日志显示: "活动渠道: Resend Email"

【场景3: 性能分析】
  1. 生成多张图片
  2. 查看日志文件
  3. 分析耗时:
     $ grep "生成耗时" logs/generator.log
  4. 计算平均值:
     $ grep "生成耗时" logs/generator.log | \
       awk '{print $NF}' | sed 's/秒//' | \
       awk '{sum+=$1;count++} END {print sum/count}'

【场景4: 数据库核对】
  1. 生成图片后查看日志
  2. 确认记录ID
  3. 在数据库中验证:
     $ psql -U postgres -d text2image_db
     text2image_db=# SELECT * FROM generated_images WHERE id=123;
