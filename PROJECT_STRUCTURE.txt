API 接口列表
═══════════════════════════════════════════════════════

GET     /                           主页面
GET     /api/health                 健康检查
POST    /api/download/batch         批量下载
GET     /api/videos                 获取视频列表 (支持搜索)
GET     /api/videos/:id             获取单个视频
DELETE  /api/videos/:id             删除视频
POST    /api/export                 导出列表
GET     /api/stats                  获取统计信息

WebSocket: ws://localhost:3000      实时通信


数据库表结构
═══════════════════════════════════════════════════════

videos 表:
- id                 (主键)
- url                (YouTube URL)
- title              (视频标题)
- filename           (文件名)
- video_format       (视频格式)
- audio_format       (音频格式)
- duration           (时长/秒)
- video_size         (视频大小/字节)
- audio_size         (音频大小/字节)
- video_path         (视频文件路径)
- audio_path         (音频文件路径)
- thumbnail_url      (缩略图URL)
- status             (状态: pending/downloading/completed/failed)
- progress           (进度: 0-100)
- error_message      (错误信息)
- created_at         (创建时间)
- completed_at       (完成时间)

索引:
- idx_videos_status
- idx_videos_created_at
- idx_videos_title
- idx_videos_filename


技术栈依赖
═══════════════════════════════════════════════════════

后端核心:
- express            Web 框架
- pg                 PostgreSQL 客户端
- ws                 WebSocket 库
- dotenv             环境变量管理

功能模块:

- html-pdf-node      PDF 生成

开发工具:

系统依赖:
